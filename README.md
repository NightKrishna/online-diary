Positivity Pocket - Micro-Journaling App

Positivity Pocket is a minimalist digital well-being app that helps you focus on the good. Every day it asks one simple question like "What made you smile today?" and you write just one positive moment.

It is private, calm, and simple. All entries are saved in your browser, no login needed. You can only log once per day to build a healthy habit, and you can view or delete your past moments anytime. It also has dark mode for night use.

Built with: HTML, CSS, JavaScript (localStorage, Date API, CRUD)

Features:
- One daily prompt
- One entry per day lock
- Private local storage
- View and delete past entries
- Light / Dark mode
- Character count and streak

This project taught me forms, dates, and CRUD basics while making something useful for mental health.
